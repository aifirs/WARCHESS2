# WARCHESS 2 — КОНЦЕПЦИЯ ДИЗАЙНА «ПРОТИВОСТОЯНИЕ ИМПЕРИЙ»

## ФИЛОСОФИЯ
WARCHESS 2 — это не просто шахматы. Это эпическая битва цивилизаций в античном стиле. Каждая партия — это противостояние империй с уникальной визуальной идентичностью.

## ФРАКЦИИ (ТЕКУЩИЕ)
- **РИМ (ЦЕЗАРЬ)** — красный, золото, лавр, орёл, колонны. Красный плащ на короле, золотые лавровые венки на фигурах.
- **МАКЕДОНИЯ (АЛЕКСАНДР)** — синий, фиолетовый, бронза, звезда Вергины, македонские копья. Король в синем плаще с золотым шлемом.
- **ГРЕЦИЯ** — белый мрамор, оливковые ветви, дорические колонны. Чистый минималистичный стиль.

## ФРАКЦИИ (МАСШТАБИРОВАНИЕ)
- **ДРЕВНИЙ ЕГИПЕТ** — песок золота, анх, фараон, обелиски.
- **ПЕРСИЯ** — тёмный пурпур, серебро, персидский ковёр, крылатые львы.

## ВИЗУАЛЬНЫЕ ЭЛЕМЕНТЫ (ГЕНЕРИРУЕМ САМИ)
- Доска: 8x8, красно-золотая палитра с тенями, мраморная текстура.
- Фигуры: стилизованные под античные статуи (король с лавром / с шлемом, королева с копьём, слон как македонский фаланги, конь как конница, ладья как колонна, пешка как легионер).
- Фон: тёмный градиент с античными узорами, золотые искры.
- Тайпография: шрифты в стиле «𝓡𝓞𝓜𝓐» — курсивные, с засечками, золотой цвет.
- Анимации: плавные ходы с подсветкой, эффект шаха (красная вспышка), эффект мата (золотой взрыв с лепестками).
- PWA: красивая картинка для закладок с заголовком «WARCHESS 2 — WAR OF EPOCH».

## МОБИЛЬНЫЙ ПРИОРИТЕТ
- Доска занимает 90% ширины экрана на телефоне.
- Панели управления (режимы, таймер, язык) — в нижнем меню или выдвижном сайдбаре.
- Кнопки достаточно крупные для пальца (min 48px touch target).
- Вертикальная ориентация предпочтительна для мобильных; горизонтальная — для планшетов.

## ТЕХНИЧЕСКИЙ СТЕК (ОБНОВЛЁННЫЙ)
- HTML5 + Vanilla JS (без сборщиков для максимальной скорости загрузки)
- CSS3 с CSS-переменными для тем фракций
- SVG для фигур (масштабируемость, скорость)
- Service Worker для PWA и офлайн-режима
- Supabase Realtime для мультиплеера по ссылке
- Простая генерация изображений через AI для активов
