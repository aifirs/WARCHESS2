# ТЕХНОЛОГИЧЕСКИЙ СТЕК
- HTML5 + CSS3 (Grid/Flexbox) с мобильной адаптацией
- Vanilla JavaScript (ES6+) — без сборщиков для простоты
- PWA (manifest + service worker) — "добавить в закладки"
- WebRTC / WebSocket или простая синхронизация через Supabase Realtime для мультиплеера
- Генерация изображений через AI для активов

# РЕЖИМЫ
- ОБУЧЕНИЕ (training): интерактивное обучение правилам
- AI MODE: игра против AI с выбираемой сложностью
- ОДИН НА ОДИН: приглашение по ссылке, синхронизация ходов

# ЯЗЫКИ
- Русский (ru) — основной по умолчанию
- Английский (en) — переключатель в интерфейсе
