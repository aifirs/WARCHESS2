# WARCHESS 2 — WAR OF EPOCH

Эпическая шахматная битва империй в античном стиле **𝓡𝓞𝓜𝓐 ⚔ 𝚬𝛌𝛌ά𝛅𝛂**.

## Название
**WARCHESS 2**

## Дата
**Июль 2026**

## Описание
WARCHESS 2 — это не просто шахматы. Это эпическая битва цивилизаций с красивым античным дизайном:
- **РИМ (ЦЕЗАРЬ)** — красный плащ, лавр, золотой орёл
- **МАКЕДОНИЯ (АЛЕКСАНДР)** — синий/фиолетовый, звезда Вергины, бронза
- **ГРЕЦИЯ** — белый мрамор, оливковые ветви, дорические колонны

## Режимы игры
- **ОБУЧЕНИЕ** — интерактивное обучение правилам (4 шага)
- **AI MODE** — игра против AI с 3 уровнями сложности (easy/medium/hard)
- **ОДИН НА ОДИН** — приглашение по ссылке с кодом комнаты (`?room=код`)

## Технологии
- HTML5 + CSS3 (мобильный приоритет)
- Vanilla JavaScript (ES6+)
- PWA (manifest + service worker)
- AI: min-max с глубиной поиска
- Мультиплеер: архитектура для Supabase Realtime

## Языки интерфейса
- Русский (ru) — по умолчанию
- Английский (en) — переключатель `RU / EN`
